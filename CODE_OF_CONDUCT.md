# Código de Conduta

Adaptado do [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

## Nosso compromisso

Queremos que participar deste projeto seja uma experiência livre de assédio para todas as pessoas,
independentemente de idade, corpo, deficiência, etnia, identidade ou expressão de gênero, nível de
experiência, escolaridade, condição socioeconômica, nacionalidade, aparência, raça, religião,
orientação sexual **ou posição política**.

## Comportamento esperado

- Ser respeitoso com opiniões e experiências diferentes.
- Dar e receber críticas construtivas, focadas no código, nos dados e no método.
- Assumir responsabilidade pelos próprios erros e aprender com eles.
- Priorizar o que é melhor para o projeto e para quem usa o site.

## Comportamento inaceitável

- Linguagem ou imagens sexualizadas, assédio público ou privado.
- Insultos, ataques pessoais, comentários depreciativos.
- **Militância partidária, propaganda eleitoral ou ataques a parlamentares, partidos ou eleitores**
  em issues, pull requests, código ou textos do site. O projeto é neutro.
- Publicar dados pessoais de terceiros sem permissão.
- Tentar manipular métricas para favorecer ou prejudicar alguém.

## Aplicação

Os mantenedores podem remover comentários, commits, issues e pull requests que violem este código,
e bloquear temporária ou permanentemente quem o desrespeitar.

Para relatar um problema de conduta, entre em contato de forma privada com um mantenedor
(veja [MAINTAINERS.md](MAINTAINERS.md)). Todo relato será tratado com sigilo.
