# Segurança

## Como relatar uma vulnerabilidade

**Não abra uma issue pública.** Use o relato privado do GitHub:
aba **Security → Report a vulnerability** neste repositório.

Inclua o que for possível: descrição, passos para reproduzir, impacto e sugestão de correção.
Responderemos em até 7 dias e daremos crédito a quem relatou, se quiser.

## Escopo

Especialmente importantes:
- Acesso a dados de outros usuários (e-mail, lista de parlamentares acompanhados).
- Falhas no login por link mágico, sessões ou descadastro por token.
- Injeção de SQL ou de conteúdo nas páginas e nos e-mails.
- Qualquer forma de alterar dados exibidos sem passar pela ingestão das fontes oficiais.

Fora de escopo: divergências de dados em relação às fontes oficiais. Essas são bem-vindas como
issue pública do tipo **"Dado divergente"**.
